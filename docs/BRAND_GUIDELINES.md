# Brand Guidelines — ToDay

> **Purpose:** Define the verbal identity of ToDay — how the brand speaks, writes, and communicates across every touchpoint.

---

## 1. Brand Voice

ToDay speaks with **quiet confidence**. The brand does not shout, exaggerate, or pressure. It states facts with clarity, lets quality speak for itself, and invites the reader into a lifestyle rather than pitching a product.

| Attribute | Application |
|-----------|-------------|
| **Confident** | Authoritative about materials and craftsmanship; no hedging language |
| **Clear** | Short sentences, precise terminology, no fluff |
| **Warm** | Approachable, human, conversational — not corporate or cold |
| **Inspirational** | Paints a picture of outdoor living, not just product specs |
| **Professional** | B2B credibility; speaks the language of importers and buyers |

## 2. Writing Style

### Principles

1. **Show, don't tell** — Describe the experience the product enables, not just its features
2. **Be specific** — "Powder-coated aluminium frame" not "high-quality materials"
3. **Stay concise** — Every sentence earns its place. Delete anything unnecessary.
4. **Use active voice** — "Our artisans craft each frame" not "Each frame is crafted"
5. **Avoid jargon** — Unless it's industry-standard terminology a buyer would expect

### Style Rules

| Rule | Correct | Incorrect |
|------|---------|-----------|
| Contractions | "It's built to last" | "It is built to last" (too formal) |
| Second person | "Your outdoor space" | "One's outdoor space" |
| Serial comma | "Sun, sand, and surf" | "Sun, sand and surf" |
| Numbers | "4-person dining set" | "Four-person dining set" |
| Measurements | "72" L × 36" W × 28" H" | "72 inches by 36 inches" |

## 3. Communication Principles

| Principle | Description |
|-----------|-------------|
| **Lead with value** | Open every section with what the reader gains |
| **Be trustworthy** | Cite specifics: materials, weight ratings, warranty, certifications |
| **Guide, don't sell** | Educate the buyer; let them conclude the product fits their needs |
| **Respect the reader** | Assume the buyer is knowledgeable; don't oversimplify |
| **One message at a time** | Each paragraph makes one point clearly |

## 4. Headline Style

| Rule | Example |
|------|---------|
| 6–10 words maximum | "Outdoor Living, Refined" |
| No periods | "Built for the Elements" |
| Active, benefit-focused | "Transform Your Patio into a Destination" |
| Occasionally provocative | "The Last Outdoor Furniture You'll Ever Buy" |
| No ALL CAPS | "Premium Outdoor Living" not "PREMIUM OUTDOOR LIVING" |

## 5. CTA Style

| Context | Style | Example |
|---------|-------|---------|
| Primary CTA | Action-oriented, benefit-driven | "Request a Catalogue" |
| Secondary CTA | Exploratory, low-commitment | "View the Collection" |
| Contact CTA | Direct, professional | "Speak with Our Team" |
| Download CTA | Value-first | "Download Spec Sheet" |

**Never use:** "Click Here", "Submit", "Buy Now" (B2B context), "Learn More" (overused)

## 6. Terminology

| Use | Do Not Use |
|-----|-----------|
| Outdoor sofa / sofa | Couch / settee |
| Dining set | Dining table (if chairs included) |
| Fire pit table | Fire table / fire feature |
| Lounge chair | Lounger / sunbed |
| Collection | Line / series |
| Spec sheet | Data sheet / brochure |
| Enquiry | Inquiry (prefer UK/international spelling) |
| Aluminium | Aluminum (prefer international spelling) |
| Weather-resistant | Waterproof (dishonest if not fully waterproof) |

**Brand name:** Always capitalise "ToDay" (T-o-D-a-y). Never use "today" or "TO-DAY".

## 7. Tone by Channel

| Channel | Tone | Example |
|---------|------|---------|
| Homepage hero | Aspirational, concise | "Outdoor Living, Elevated." |
| Product description | Technical, precise | "Powder-coated aluminium frame with rust-proof hardware." |
| About page | Warm, storytelling | "Founded by craftsmen who believed outdoor spaces deserve better design." |
| Blog | Helpful, educational | "A guide to choosing weather-resistant outdoor furniture." |
| Contact page | Professional, direct | "Tell us about your project. We'll respond within one business day." |
| Error / 404 | Friendly, concise | "This page is enjoying the outdoors. Let's get you back inside." |

## 8. Words to Avoid

| Word / Phrase | Why to Avoid |
|--------------|--------------|
| "High-quality" | Vague — be specific instead |
| "State-of-the-art" | Cliché, overused |
| "Revolutionary" | Unrealistic expectation |
| "Best-in-class" | Claim without evidence |
| "Solution" | Corporate jargon |
| "Leverage" | Overused business-speak |
| "Game-changer" | Excessive |
| "World-class" | Meaningless without proof |
| "Innovative" | Overused; show innovation through specifics |
